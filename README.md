 # Ситстема управления рецептами
 Это консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", 
 масштабировать порции и генерировать список покупок.
 


## Установка

Склонировать репозиторий:

```bash
git clone <ссылка на репозиторий>
cd <папка проекта>
pip install -r requirements.txt
pytest
```
